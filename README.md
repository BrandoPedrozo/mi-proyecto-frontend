Proyecto inicial de la asignatura **Desarrollo de Aplicaciones Web y Sistemas Operativos**.

## Descripción
Estructura básica de un proyecto front-end con las carpetas:

- `js/` → Scripts
- `assets/` → Imágenes y recursos
- `index.html` → Página principal
